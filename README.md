## Overview

This project builds and evaluates a reproducible intrusion detection pipeline on the CICIDS2017 
dataset. It trains three machine learning models for 15-class multi-class attack detection at the 
network flow level, evaluates them under two split strategies (stratified and temporal day-based), 
and maps all detected attack types to MITRE ATT&CK techniques to produce security engineering 
outputs suitable for SOC use.

## Reproducing All Results

Run these commands in order:

```bash
# Step 1: Build and clean the dataset
python -m src.prepare_data

# Step 2: Leakage audit
python -m src.leakage_check

# Step 3: Train models (both split strategies)
python -m src.train --split strat --out-dir models/baseline_strat
python -m src.train --split day   --out-dir models/baseline_day

# Step 4: Evaluate models
python -m src.eval --split strat --models-dir models/baseline_strat --out-dir reports/metrics_strat
python -m src.eval --split day   --models-dir models/baseline_day   --out-dir reports/metrics_day

# Step 5: Generate security outputs
python -m src.mitre_alerts --metrics-dir reports/metrics_strat --out-dir reports/alerts
python -m src.traffic_analysis
python -m src.report --metrics-dir reports/metrics_strat --alerts-dir reports/alerts

# Step 6: Split comparison report
python -m src.eval_split_compare --skip-train \
  --models-strat models/baseline_strat \
  --models-day   models/baseline_day \
  --metrics-strat reports/metrics_strat \
  --metrics-day   reports/metrics_day
```

## Key Results

| Model | Macro Precision | Macro Recall | Macro F1 | ROC AUC |
|---|---|---|---|---|
| Logistic Regression | 0.2240 | 0.8199 | 0.2610 | 0.9599 |
| Random Forest | 0.8776 | 0.8541 | 0.8309 | 0.9928 |
| **XGBoost** | **0.9161** | **0.8560** | **0.8742** | **0.9996** |

**Evaluation split**: Stratified (80/10/10), 15-class multi-class, macro-averaged.

**Distribution shift finding**: Under the temporal day split (train Mon–Wed, test Thu), 
all models drop to macro F1 ≈ 0.06. This reflects a limitation imposed by the dataset's 
temporal structure — each capture day contains a distinct and non-overlapping set of attack 
types — rather than a model failure. This finding demonstrates that temporal distribution 
shift is a fundamental challenge in deploying flow-based IDS models.

## Dataset

**CICIDS2017** — Canadian Institute for Cybersecurity  
2,313,150 flows | 73 features | 15 attack classes  

Leakage columns dropped before modelling:
- `Flow Bytes/s`, `Flow Packets/s`, `Fwd Packets/s`, `Bwd Packets/s`  
  (algebraically derived from other features — would allow shortcut learning)

Near-duplicate leakage audit found ~28,000 flow groups crossing the day-split 
boundary and ~26,000 crossing the stratified split boundary. This is a known 
limitation of flow datasets without 5-tuple identifiers, documented in 
`reports/leakage_check.md`.

| Tactic | Attack Types |
|---|---|

## Notes

- `train_baseline.py` and `train_multiclass_baseline.py` are early exploratory scripts 
  and are superseded by `train.py`. They are kept for reference only.
- All models use `random_state=42` for reproducibility.
- XGBoost under the day split requires a label remapping step (saved as 
  `xgboost_label_remap.json`) because training classes are non-contiguous when 
  attack types are separated by day.
